Interfaces y funciones

Qué aprenderás

Una interfaz describe la forma esperada de un objeto. Declara los campos realmente necesarios y usa readonly para expresar que una operación no debe modificarlos.

Ejemplo guiado

Trabaja en un proyecto o carpeta de práctica independiente. Lee el ejemplo, identifica sus entradas y predice el resultado antes de ejecutarlo. Los fragmentos ilustran una idea; cuando dependen de otras clases o funciones, intégralos en el proyecto de las lecciones anteriores.

interface Curso { readonly id: number; titulo: string; }
function nombre(curso: Curso): string { return curso.titulo; }

Tu práctica

Define una interfaz para una lección y una función que devuelva su etiqueta.

Comprueba tu solución

La función recibe solo los campos requeridos y tiene retorno explícito.

  • Ejecuta un caso válido y uno que represente un error o límite.
  • Guarda el código y anota qué cambiaste, qué esperabas y qué ocurrió.
  • Explica el resultado con tus palabras antes de marcar la lección como completada en Kido.
