Promesas y errores de red

Qué aprenderás

fetch no rechaza automáticamente por todos los errores HTTP. Comprueba response.ok y diferencia carga, resultado vacío y fallo. Restaura el estado de carga mediante finally.

Ejemplo guiado

Trabaja en un proyecto o carpeta de práctica independiente. Lee el ejemplo, identifica sus entradas y predice el resultado antes de ejecutarlo. Los fragmentos ilustran una idea; cuando dependen de otras clases o funciones, intégralos en el proyecto de las lecciones anteriores.

async function cargar(url) {
  const respuesta = await fetch(url);
  if (!respuesta.ok) throw new Error(`HTTP ${respuesta.status}`);
  return respuesta.json();
}

Tu práctica

Usa un archivo JSON local y simula una ruta inexistente.

Comprueba tu solución

El error es visible y se puede reintentar sin duplicar resultados.

  • Ejecuta un caso válido y uno que represente un error o límite.
  • Guarda el código y anota qué cambiaste, qué esperabas y qué ocurrió.
