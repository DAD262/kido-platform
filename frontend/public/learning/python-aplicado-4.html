Persistir tareas en JSON

Qué aprenderás

JSON intercambia objetos simples. Al leer un archivo debes validar su estructura antes de convertirlo a objetos del dominio. No asumas que un archivo existente contiene datos válidos.

Ejemplo guiado

Trabaja en un proyecto o carpeta de práctica independiente. Lee el ejemplo, identifica sus entradas y predice el resultado antes de ejecutarlo. Los fragmentos ilustran una idea; cuando dependen de otras clases o funciones, intégralos en el proyecto de las lecciones anteriores.

import json
from pathlib import Path
archivo = Path("tareas-demo.json")
datos = [{"titulo": "Practicar", "completada": False}]
archivo.write_text(json.dumps(datos, ensure_ascii=False), encoding="utf-8")

Tu práctica

Lee el JSON y rechaza estructuras que no sean una lista de tareas válidas.

Comprueba tu solución

Acentos conservados; un JSON roto no reemplaza el estado previo.

  • Ejecuta un caso válido y uno que represente un error o límite.
  • Guarda el código y anota qué cambiaste, qué esperabas y qué ocurrió.
  • Explica el resultado con tus palabras antes de marcar la lección como completada en Kido.
