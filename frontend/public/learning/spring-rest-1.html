Un recurso y su controlador

Qué aprenderás

Una API expone recursos mediante rutas y verbos HTTP. Un controlador debe traducir la solicitud y delegar reglas de negocio, no concentrar persistencia y validación de permisos.

Ejemplo guiado

Trabaja en un proyecto o carpeta de práctica independiente. Lee el ejemplo, identifica sus entradas y predice el resultado antes de ejecutarlo. Los fragmentos ilustran una idea; cuando dependen de otras clases o funciones, intégralos en el proyecto de las lecciones anteriores.

@RestController
@RequestMapping("/cursos")
class CursoController {
  @GetMapping("/{id}")
  CursoDto obtener(@PathVariable long id) {
    return new CursoDto(id, "Java");
  }
}
record CursoDto(long id, String titulo) {}

Tu práctica

Crea el proyecto desde Spring Initializr y añade una ruta GET de consulta.

Comprueba tu solución

GET /cursos/1 responde JSON; una ruta inexistente no responde una compra aprobada.

  • Ejecuta un caso válido y uno que represente un error o límite.
  • Guarda el código y anota qué cambiaste, qué esperabas y qué ocurrió.
  • Explica el resultado con tus palabras antes de marcar la lección como completada en Kido.
