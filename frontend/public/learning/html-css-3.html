Caja, espaciado y tipografía

Qué aprenderás

El modelo de caja distingue contenido, relleno, borde y margen. Define box-sizing para que el ancho sea predecible. Limita el ancho de lectura y permite que el texto crezca sin ocultarse.

Ejemplo guiado

Trabaja en un proyecto o carpeta de práctica independiente. Lee el ejemplo, identifica sus entradas y predice el resultado antes de ejecutarlo. Los fragmentos ilustran una idea; cuando dependen de otras clases o funciones, intégralos en el proyecto de las lecciones anteriores.

* { box-sizing: border-box; }
main { max-width: 70rem; margin: auto; padding: 1.5rem; }
body { font-family: system-ui; line-height: 1.6; }

Tu práctica

Crea una tarjeta con título, texto y enlace sin asignar altura fija al contenido.

Comprueba tu solución

La tarjeta no recorta texto al ampliar la fuente.

  • Ejecuta un caso válido y uno que represente un error o límite.
  • Guarda el código y anota qué cambiaste, qué esperabas y qué ocurrió.
  • Explica el resultado con tus palabras antes de marcar la lección como completada en Kido.

Para profundizar

Consultar la documentación oficial. Esta guía de Kido es una explicación original con ejemplos de práctica; el enlace amplía el tema y no implica una certificación de esa organización.
