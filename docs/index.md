# Kido

Kido es una plataforma distribuida para cursos digitales gratuitos y pagados.

El avance de Unidad 1 incluye los microservicios Curso e Inscripción, configuración centralizada, Eureka, Gateway, balanceo entre dos instancias, PostgreSQL y Flyway.

Consulta el [brief técnico](brief-tecnico.md), el [producto de Unidad 1](u1-producto.md) y la [guía de sustentación S5](guia-s5.md).
