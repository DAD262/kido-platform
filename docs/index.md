# Kido

Kido es una plataforma distribuida para cursos digitales gratuitos y pagados.

El repositorio ya contiene los cuatro microservicios de negocio acordados: Curso, Inscripción, Pago y Notificación, además de Config Server, Eureka y Gateway. El avance de Adan implementó Curso e Inscripción; Midwar continuó sobre el mismo código e incorporó compras, comisión, saldo docente, retiros, reembolsos y notificaciones.

Para la evaluación S5 siguen disponibles los elementos exigidos de Unidad I: REST persistente, configuración DEV/PROD, descubrimiento, Gateway y balanceo entre dos instancias de Cursos.

Consulta el [brief técnico](brief-tecnico.md), el [producto de Unidad 1](u1-producto.md), la [guía S5](guia-s5.md) y el [avance de Midwar](avance-midwar.md).
